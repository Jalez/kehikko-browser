Kind: feature

- **Other modules can open pages here without knowing this one.** Browser now says it shows web pages and which tool opens an address, so a module that wants a page shown finds it by what it does.
- **Says what its project folder holds.** Browser now tells other modules what it keeps in its folder, so a module that shows the project's files can name the owner.

## For agents

- `services['page.viewer']` is `{ name: 'Browser', tool: 'navigate' }`; `navigate` takes `{ url }`.
- `services['module.folders']` declares `.kehikot/browser/` (not derived).
