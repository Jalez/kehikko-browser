Kind: fix

- **Always opens what you point at now.** Picking an issue or change quickly after another no longer leaves the older one's page on screen, and picking back the page that was already shown while another was loading now brings it back.
- **A page that fails to load is tried once more.** If it fails again, Browser says so with the address and a Try again button, instead of leaving the old page up.
- **Nothing older lands over a pick.** An address you typed, a slow answer for an earlier pick, a failed earlier load, or the address remembered for the place no longer replaces the page you just picked.
- **Keeps trying when the app is slow to answer.** A pick the app did not answer about is asked again, and a pick with no page yet opens as soon as the app has read it. Turning following back on opens what is picked now.
- **Says what it is loading.** While a picked page opens, the cover names it by its title.
