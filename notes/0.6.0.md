- **A picked issue or merge request is shown as opening at once.** The moment you pick one in References, a slim line says "Opening !4013…" and the address bar shows where it is going, instead of keeping the old address until the forge answers. The line goes away when the new page's first picture arrives, and the address bar corrects itself if the forge redirects.
- **One click opens the page once.** Opening a link from References used to load the page twice when the same click also picked the item, which made it slower. Now it is loaded once.
- **A pick made while the browser was reconnecting is no longer lost.** It opens as soon as the browser is back, as long as it is still what you have picked.
