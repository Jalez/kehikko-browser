- **A real browser in a container.** Open the issues and pull requests the canvas is about, or the app you are building, in a real Chromium that fits the container and takes your pointer and keys.
- **Your logins stay.** Browser keeps its own profile, separate from your own Chrome, so you stay signed in across restarts.
- **Agents can use it with you.** Agents can open pages, read them, click, type and take screenshots in the same browser you see.
- **Playwright connects to the same browser.** Run › Playwright endpoint… shows the address and ready-to-paste snippets for attaching Playwright to it.
